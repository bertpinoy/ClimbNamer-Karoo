Fixes for navigating to a route from elsewhere (e.g. from home): the point where the approach joins the route is now taken from the map (the route point closest to the end of the approach), because the value the Karoo reports can be wrong. Climbs after the join point get the right names again. A climb that runs past the end of the navigated path is named from the part that exists. The diagnostics line shows both join points (ClimbNamer's and the Karoo's).
